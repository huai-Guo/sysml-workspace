# SysML Workspace

A unified, tri-modal modeling workbench for **OMG SysML v2**:
1. **Text-First Modeling**: Rich CodeMirror editor with real-time official OMG SysML v2 Pilot JVM validation, syntax diagnostics, and AST extraction.
2. **Interactive Visual Diagramming**: Bidirectional semantic projection (`SysML Code <-> Diagram IR`), nested container layout, and semantic canvas connection editing.
3. **Agent Co-pilot**: Natural language SysML generation, intent-based patch/revision, and automated iterative repair against official compiler diagnostics.
4. **Scoped Domain Knowledge Engine**: Lightweight engineering evidence & requirement retrieval (without bloated OCR benchmark overhead).

## Key Design Principles

1. **SysML Text as Single Source of Truth (SSOT)**:
   - The official SysML v2 syntax is always the canonical representation.
   - Diagrams are deterministic projections of the SysML semantic model.
   - Visual edits emit high-level **Semantic Commands** that modify the SysML source code cleanly.
2. **Deterministic Quality Gate**:
   - Every model generated by the Agent or written by the user is verified by the pinned OMG SysML v2 Pilot JVM.
   - LLMs are never assumed to output flawless syntax; self-repair cycles automatically fix compiler diagnostics.
3. **In-Process Native Rendering**:
   - The diagram engine runs directly in-process, eliminating network hops and microservice failures.
4. **Pruned & Purpose-Driven RAG**:
   - Stripped away heavyweight OCR benchmarks (OmniDocBench, TableBank) from the old `sysml-rag`.
   - Preserved scoped technical document retrieval for Requirement-to-Model tracing and standard library lookup.

## Quick Start

### 1. Backend Setup

Prerequisites:
- Python >= 3.11
- Java 21 (for official SysML v2 Pilot compiler)
- PostgreSQL (optional for multi-user production; in-memory/test supported)

```bash
cd backend
python -m venv .venv
# On Windows:
.venv\Scripts\activate
# On Linux/macOS:
source .venv/bin/activate

pip install -e ".[dev]"
```

Test the official Pilot validator:
```bash
python -c "
import asyncio
from sysml_workspace.parser import PilotSubprocessValidator

validator = PilotSubprocessValidator(tooling_dir='tooling/sysml-validator')
result = asyncio.run(validator.validate('package Test { part def Car; }'))
print('Valid:', result.valid)
"
```

### 2. Frontend Build

Prerequisites:
- Node.js >= 20

```bash
cd frontend
npm ci
npm test
npm run build
```

This compiles `workbench.js` directly into the backend's static directory.

### 3. Run the Workbench

```bash
sysml-workspace api --host 127.0.0.1 --port 8000
```
Open `http://127.0.0.1:8000` in your browser.
